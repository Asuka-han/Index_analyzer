## 5. 一键运行与复现方式

### 5.1 命令行（研发/分析）

- 基础分析：`python scripts/run_industry_analysis.py`
- 高级分析：`python scripts/run_industry_advanced.py`

### 5.2 Web UI（业务同事）

- 直接运行：`streamlit run ui/industry_app.py`
- 在UI中点击“开始分析”即可一键生成结果与图表。

### 5.3 EXE / Docker（独立分发）

- EXE：
	- 构建：`powershell -ExecutionPolicy Bypass -File packaging/build_exe_with_spec.ps1`
	- 运行：`powershell -ExecutionPolicy Bypass -File packaging/run_exe.ps1`
- Docker：
	- 构建：`docker build -t industry-app .`
	- 运行：`docker run --rm -p 8501:8501 industry-app`
