# 行业景气度指数详细说明

## 1. 文档目的

本文档用于补齐“行业景气度指数构建任务指南”中第2项交付要求，覆盖以下内容：

1. 汽车行业和房地产行业的指标选择及理由。  
2. 每个行业2-4个核心指标及其数据来源（AKShare / Excel / SQLite）。  
3. 指数计算逻辑详解，并与 `fundamental_economy.py` 对比异同。  
4. 两个行业最终景气度指数走势展示。

## 2. 指标选择与理由

### 2.1 汽车行业

汽车产业链覆盖“终端需求—生产—上游配套—原材料成本”四个关键环节，因此采用以下4个指标构建扩散指数：

1. **乘用车周度销量（AUTO_SALES_W）**  
   - 理由：直接反映终端销售热度，是最贴近需求侧变化的高频指标。  
2. **汽车产量月度数据（AUTO_PRODUCTION_M）**  
   - 理由：代表制造端景气水平，可验证销售变化是否向生产传导。  
3. **轮胎开工率（TIRE_OPERATING_RATE）**  
   - 理由：作为上游景气代理变量，能较早体现产业链运行强度。  
4. **钢铁价格指数（STEEL_PRICE_INDEX）**  
   - 理由：反映核心原材料成本与景气环境，补充成本侧信息。

### 2.2 房地产行业

房地产景气主要由“销售—投资—价格—土地市场”共同驱动，采用以下4个指标：

1. **商品房销售面积（REAL_ESTATE_SALES）**  
   - 理由：直接体现地产需求与成交活跃度。  
2. **房地产开发投资完成额（REAL_ESTATE_INVESTMENT）**  
   - 理由：反映开发端资本开支强弱与中期供给意愿。  
3. **百城住宅价格指数（HOUSE_PRICE_INDEX）**  
   - 理由：补充价格维度，刻画市场预期与景气方向。  
4. **土地成交面积（LAND_TRANSACTION_AREA）**  
   - 理由：作为前端拿地行为指标，可辅助判断地产周期拐点。

## 4. 指数计算逻辑（含与 `fundamental_economy.py` 对比）

### 4.1 行业指数计算流程

以 `IndustryAnalyzer._calculate_signals()` 为核心，流程如下：

1. **时间索引标准化与缺失值处理**  
   - 将索引转为 `DatetimeIndex`，去重后转为日频。  
   - 采用 `interpolate(method="time") + ffill + bfill` 补齐缺口。  

2. **按指标配置降频**  
   - 通过配置中的 `freq_method`（如 `last`）聚合到月频（`ME`）。

3. **方向信号计算**  
   - 对每个指标计算 `np.sign(x.diff())`，得到 `+1/0/-1`。  
   - 形成 `*_Direction` 列，并生成综合方向 `final_signal`：  
     - 当期各方向列求和 > 0，则 `final_signal=1`；否则 `-1`。

4. **三类指数输出**  
   - **Diffusion_Index_A**：方向矩阵横向均值（扩散指数）。  
   - **Base_Index_B**：以100为基准，累计 `Diffusion_Index_A`。  
   - **YoY_Index_C**：`Base_Index_B` 的12期同比变化率（%）。

### 4.2 与 `fundamental_economy.py` 的相同点

- 核心扩散思想一致：`direction_df = period_df.apply(lambda x: np.sign(x.diff()))`。  
- 指数三层结构一致：`Diffusion_Index_A / Base_Index_B / YoY_Index_C`。  
- 缺失值与日频化处理框架一致。  
- 可视化均为三图结构（A/B/C联动展示）。

### 4.3 与 `fundamental_economy.py` 的不同点

1. **数据入口不同**  
   - `fundamental_economy.py` 读取 `DataManager` 中“经济指标”聚合结果；  
   - `industry_analyzer.py` 由 `DataConnector` 按指标实时拉取并拼接，天然支持多数据源。

2. **重采样策略更细粒度**  
   - 行业分析按“每个指标的 `freq_method`”动态组装聚合字典；  
   - 经济分析通常使用按类别统一参数表。

3. **基期锚定策略不同**  
   - 经济分析含 `base_date` 校验与替代逻辑；  
   - 行业分析直接以序列起点累计（固定初值100）。

4. **输出组织不同**  
   - 行业分析新增双行业联动输出（`industry_full_report.xlsx`）与交互式HTML图表。
