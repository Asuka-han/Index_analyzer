# 高频经济指数分析系统

## 项目概述

本项目是一个面向量化研究与宏观分析的高频经济指数分析系统，旨在通过多源数据采集、自动化预处理与模块化信号生成，为研究人员和投资决策提供稳定、可解释的高频因子与综合信号。

核心目标包括：
- 支持 Wind、Excel、AkShare 等多种数据源的按需接入与增量更新；
- 提供可复用的数据管道（DataPipeline）和持久化管理（DataManager），确保数据质量与可追溯性；
- 构建分维度分析器（经济、货币、信用、国际、估值、资金、技术），独立生成信号并支持多因子合成与回测适配；
- 易于扩展的预处理与指标配置机制，便于添加新指标与自定义规则。

目标用户为量化研究员、宏观分析师与产品化工程团队。系统输出包括面向研究的时序信号表、Excel 报表与行业分析结果，便于后续统计检验、可视化与生产部署。

## 功能特性

### 多维度分析
- **基本面信号**：经济指标、货币指标、信用指标
- **国际面信号**：国际经济指标
- **资金面信号**：资金流向指标
- **估值面信号**：估值指标
- **技术面信号**：技术分析指标 (MACD, RSI)

### 数据处理
- 支持多种数据源 (Wind, Excel, SQLite, AkShare)
- 自动数据更新和预处理
- 智能异常值处理
- 灵活的存储策略

### 信号合成
- 各维度信号独立生成
- 综合信号计算（基于1, 0, -1信号结构）
- 月度频率信号生成

## 核心模块

### 数据管理模块 (DataPipeline)
- 统一数据获取接口
- 增量更新机制
- 自动预处理功能
- 分类存储管理

### 分析器模块 (Analyzers)
- EconomyAnalyzer: 经济面分析
- MonetaryAnalyzer: 货币面分析
- CreditAnalyzer: 信用面分析
- InternationalAnalyzer: 国际面分析
- ValuationAnalyzer: 估值面分析
- CapitalAnalyzer: 资金面分析
- TechIndicatorAnalyzer: 技术面分析

## 使用方法

### 核心任务脚本 (src/tasks/)

#### 1. 数据更新脚本
```bash
python -m src.tasks.task_update_data --category all --incremental
```

**作用**: 
- 更新各类经济指标数据
- 支持增量更新和全量更新
- 自动处理数据预处理和存储

**参数说明**：
- `--category`: 更新类别 (all, 经济指标, 货币指标, 信用指标, 国际指标, 估值指标, 资金指标)
- `--incremental`: 增量更新模式
- `--reprocess`: 重新处理所有数据

**结果**: 
- 更新 `data/raw/` 目录下的原始数据文件
- 生成处理后的数据到 `data/processed/` 目录

#### 2. 数据分析脚本
```bash
python -m src.tasks.task_analyze_data --start_date 2012-01-01 --end_date 2025-12-31
```

**作用**:
- 执行多维度经济指标分析
- 生成基本面、国际面、资金面、估值面、技术面等信号
- 合成综合决策信号

**参数说明**：
- `--start_date`: 分析开始日期 (YYYY-MM-DD)
- `--end_date`: 分析结束日期 (YYYY-MM-DD)


**结果**:
- 生成 `multi_factor_analysis.xlsx` 文件
- 在 `result/` 目录下保存带时间戳的分析结果文件
- 包含各维度信号和最终决策信号

## 分析结果

分析结果以Excel格式保存在 `result/` 目录中，包含：
- 各维度信号
- 基本面信号 (经济面+货币面+信用面)
- 综合决策信号

最终决策信号规则：
- 总信号 > 3: 买入信号 (1)
- 总信号 < -3: 卖出信号 (-1)  
- 其他情况: 持平信号 (0)

### 行业分析脚本 (scripts/)

#### 3. 行业分析脚本
```bash
python scripts/run_industry_analysis.py
```

**作用**:
- 对特定行业（汽车行业、房地产行业）进行景气度指数分析
- 生成行业专用的分析报告和图表

**结果**:
- 在 `result/industry/` 目录下生成行业分析结果
- 包含行业指数、图表和分析报告

#### 4. 高级行业分析脚本
```bash
python scripts/run_industry_advanced.py
```

**作用**:
- 执行高级行业分析任务
- 进行跨行业对比分析

**结果**:
- 在 `result/industry_advanced/` 目录下生成高级分析结果
- 包含行业对比分析和综合评估

#### 5. 行业配置更新脚本
```bash
python scripts/update_industry_config.py
```

**作用**:
- 更新高频宏观数据指标库中的行业指标配置
- 添加新的行业指标定义（如乘用车销量、房地产销售等）

**结果**:
- 修改 `高频宏观数据指标库.xlsx` 配置文件
- 添加新的行业指标配置到选定指标和高级配置工作表

#### 6. 样本数据生成脚本
```bash
python scripts/build_industry_sample_data.py
```

**作用**:
- 生成行业分析所需的样本Excel和SQLite数据
- 为汽车行业和房地产行业创建测试数据

**结果**:
- 在 `data/raw/` 目录下生成样本数据文件
- 创建 `汽车行业指标.xlsx`、`房地产行业指标.xlsx` 等文件
- 创建对应的SQLite数据库文件

### 7. 信号有效性分析脚本
```bash
python stat_vs_mkt_combo.py
```

**作用**:
- 分析生成的信号与市场表现的相关性
- 评估信号预测准确性
- 生成可视化图表

**结果**:
- 生成 `signal_analysis.png` - 信号准确率对比图
- 生成 `benchmark_with_signals.png` - 指数走势与信号标注图
- 生成 `signal_analysis_full_results.xlsx` - 详细分析数据

### 8. 数据诊断脚本
```bash
python test_data.py
```

**作用**:
- 诊断数据源连接和数据获取情况
- 验证各指标数据的可用性和完整性

**结果**:
- 控制台输出各指标的数据获取情况
- 显示数据行数、日期范围、最新值等信息

### 配置管理

系统通过 `高频宏观数据指标库.xlsx` 进行配置管理，包含：
- 指标ID和名称
- 数据源配置
- 存储方式设置
- 预处理规则

## 注意事项

1. 数据源依赖于Wind等专业金融数据提供商
2. 部分高级指标数据有时间限制（如LPR数据从2019年8月20日开始）
3. 系统默认使用沪深300指数 (000300.SH) 作为基准
4. 建议定期更新数据以保持分析准确性
